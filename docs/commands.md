# 指令手册

命令前缀遵循 NoneBot 配置 `COMMAND_START`（默认无前缀或 `/` 均可）。
标注【管理员】需群管/群主/SUPERUSER，【SUPERUSER】需机器人超级用户。

## 基础

| 指令 | 说明 |
|---|---|
| `帮助maimaiDX` | 指令总览图 |
| `项目地址maimaiDX` | 项目仓库地址 |

## 绑定与设置（bind）

| 指令 | 说明 |
|---|---|
| `绑定水鱼 <用户名>` | 绑定水鱼（公开查询档） |
| `绑定水鱼`（QQ 平台） | 直接以 QQ 号公开查询 |
| `绑定水鱼token <Import-Token>` / `水鱼授权码 <Token>` | 水鱼全量成绩档（牌子/表格需要） |
| `绑定落雪` | 发起落雪 OAuth 授权（需部署配置） |
| `绑定落雪 <个人Token>` / `绑定落雪 <好友码>` | 落雪直绑 |
| `落雪授权码 <授权码>` / `lxcode <授权码>` | 回填 OAuth 授权码（20 分钟内有效） |
| `绑定日服 <SEGA ID> <密码>` | 绑定日服 maimai NET（仅限私聊；密码落库；绑定即验证登录） |
| `数据源 <0\|1\|2>` | 切换 水鱼/落雪/日服 NET（目标源未绑定时拒绝） |
| `主题 <0|1>` | 切换绘图主题 prism_plus/circle |
| `我的绑定` | 查看当前绑定（Token 打码） |
| `解绑` | 解除绑定 |

## 查歌（music_query）

| 指令 | 说明 |
|---|---|
| `查歌 <标题> [页]` | 标题模糊搜索 |
| `定数查歌 <定数> [页]` / `定数查歌 <最小> <最大> [页]` | 按定数搜索 |
| `bpm查歌 <bpm> [页]` / `bpm查歌 <最小> <最大> [页]` | 按 BPM 搜索 |
| `曲师查歌 <曲师> [页]` | 按曲师（大小写不敏感） |
| `谱师查歌 <谱师> [页]` | 按谱师 |
| `<名称>是什么歌 [页]` | 别名优先 → ID → 标题关键词；含柚子投票中提示 |
| `id <数字>` | 按 ID 查谱面 |

单首出谱面卡，2–5 首文本列表，更多出列表图（25/页）。

## 别名（alias）

| 指令 | 说明 |
|---|---|
| `<名称>有什么别名` / `id <数字>有什么别名` | 查询别名（柚子 + 本地） |
| `添加本地别名 <id> <别名>` | 写入本地库并热更新 |
| `添加别名 <id> <别名>` | 向柚子提交公开申请 |
| `同意别名 <TAG>` | 为进行中的投票赞成 |
| `当前投票 [页]` | 进行中投票列表（25/页） |
| `开启/关闭别名推送`【管理员】 | 群级推送开关 |
| `全局开启/关闭别名推送`【SUPERUSER】 | 批量设置所有群 |
| `更新别名库`【SUPERUSER】 | 重新拉取曲库与别名 |

别名申请事件（SSE）会推送到已开启推送的群（合并转发优先）。

## 查分（score_query）

| 指令 | 说明 |
|---|---|
| `b50` | 查询自己的 B50（数据源为日服 NET 时按日服定数与现行版本组装） |
| `b50 <水鱼用户名>` | 水鱼公开代查（无需绑定） |
| `b50 @某人` / `ap50 @某人` | 代查他人：优先用对方绑定凭据；对方未绑定时，OneBot 等 QQ 平台回退水鱼按 QQ 公开查询，其余平台提示无法代查 |
| `minfo <ID|曲名|别名> [@某人]` | 单曲成绩卡（@某人 代查其成绩）。曲名/别名同时命中标准谱与 DX 谱时列出两条 id（同「是什么歌」），用 `minfo <ID>` 指定要看的谱面；写 `minfo dx<别名>` 可直接看 DX 谱。要看的这张谱面（标准谱或 DX 谱）没有任何难度成绩时提示「尚未游玩过该曲目」，不输出全灰的成绩卡 |
| `ginfo [绿黄红紫白]<曲>` | 谱面游玩统计 + 评级分布图（需水鱼开发者 Token） |

> 日服 NET 数据源（`数据源 2`）当前支持 `b50` / `minfo`；其余查分指令会提示暂不支持。
> NET 查询采用窗口缓存：一次抓取（约 5-15 秒）后窗口内（默认 15 分钟，
> `AWMC_NET_COOLDOWN_MINUTES` 可调）重复查询秒回，防止官方风控。
> 水鱼公开查询的凭据优先级：绑定用户名 > QQ 号（聊天 QQ 与水鱼账号 QQ 不一致时以用户名为准）。

## 工具（score_tools）

| 指令 | 说明 |
|---|---|
| `分数线 <难度色><id> <线>` | TAP/GREAT 容错与 BREAK 50 落等价 |
| `分数线 帮助` | 分数线说明 |
| `我要上N分` | 推分推荐（如 我要上20分） |
| `我要在<等级>上加N分` | 指定等级推分（如 我要在紫13+上加10分） |
| `查看排名 [页|用户名]` | 水鱼 RA 排行榜（50/页） |
| `我的排名` | 自己在水鱼榜的名次（需绑定水鱼） |

## 表格（tables）

| 指令 | 说明 |
|---|---|
| `<等级>定数表` | 如 13+定数表 |
| `<等级><评价>完成表` | 如 13fc完成表 / 14sssp完成表 |
| `<等级><评价>进度 [页]` | 如 13fc进度 |
| `<版本><牌种>完成表 / 进度` | 如 真极完成表 / 樱极进度 / 舞舞进度（牌种按各代真实牌表校验，如真代无极将、霸仅者） |
| `牌子条件` | 牌子达成条件说明 |
| `<等级|定数>分数列表 [页]` | 如 13+分数列表 / 13.7分数列表 |
| `更新定数表 / 更新完成表`【SUPERUSER】 | 本插件实时渲染，无需更新 |

## 娱乐（random_song / fortune / guess）

| 指令 | 说明 |
|---|---|
| `来个/随个/给个 [dx|sd|标准][色]<等级>` | 随机谱面（如 随个紫13+） |

| `开启/关闭mai猜歌`【管理员】 | 群级开关 |

## 排卡（arcade）

| 指令 | 权限 | 说明 |
|---|---|---|
| `开启排卡` / `关闭排卡` | 管理员 | 群级开关；部署默认关（`AWMC_ARCADE_ENABLED`），关闭群内指令静默不响应 |
| `帮助maimaiDX排卡` | — | 排卡帮助（不设开关门禁，便于发现开启入口） |
| `添加机厅 <店名> <地址> <机台数> [别称...]` | SUPERUSER | 自定义 ID≥10000 |
| `删除机厅 <店名>` | SUPERUSER | |
| `添加机厅别名 <店名|ID> <别名>` / `删除机厅别名 <别名>` | — | |
| `修改机厅 <店名|ID> 数量 <数量>` | 管理员 | |
| `订阅机厅 <店名|ID>` / `取消订阅机厅` | 管理员 | 订阅后人数指令仅对本群订阅生效 |
| `查看订阅` | — | 本群订阅列表 |
| `查找机厅 <关键词>` | — | 店名/地址/别称模糊（≥5 条转图） |
| `<店名>设置/=,加/+,减/- <人数>[人|卡]` | — | 人人可排（对齐原版）；仅本群订阅机厅；单次变更上限 `awmc_arcade_max_delta`；无店名消息（如 `1+1`）静默忽略 |
| `<店名>有多少人/几人/几卡` | — | 查询排卡人数 |
| `机厅几人` / `jtj` | — | 本群全部订阅机厅 |

每日 4 点自动同步华立官方机厅数据并清零排卡人数。
除帮助与开关指令外，排卡指令在群内均受「开启排卡」门禁（对齐 Hoshino 原版
`maimaiDX排卡` Service 默认关闭、按群开通），私聊按部署默认值。
