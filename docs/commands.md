# 指令手册

命令前缀遵循 NoneBot 配置 `COMMAND_START`（默认无前缀或 `/` 均可）。
标注【管理员】需群管/群主/SUPERUSER，【SUPERUSER】需机器人超级用户。

## 基础

| 指令 | 说明 |
|---|---|
| `舞萌帮助`（`wmhelp` / `mai帮助`，旧词 `帮助maimaiDX` 保留） | 指令总览（合并转发； SUPERUSER 额外可见「管理」节点） |
| `舞萌帮助 <类别\|指令\|指南>` | 分类清单 / 单条指令详情 / 流程指南（如 `舞萌帮助 查分上手`） |
| `项目地址maimaiDX` | 项目仓库地址 |

## 查分（score_query）

| 指令 | 说明 |
|---|---|
| `b50` | 查询自己的 B50（数据源为日服 NET 时按日服定数与现行版本组装） |
| `b40` | 无条件全量 b40：旧系数 FiNALE 口径重算全部成绩（恒拆 25+15），头部含「底分+段位分」称号条 |
| `b50 <水鱼用户名>` | 水鱼公开代查（无需绑定） |
| `b50 @某人` / `ap50 @某人` | 代查他人：优先用对方绑定凭据；对方未绑定时，OneBot 等 QQ 平台回退水鱼按 QQ 公开查询，其余平台提示无法代查 |
| `<条件串>50 [@某人]` | **条件50**：条件过滤的 B50（详见下方「条件组合查询」） |
| `<条件串>40 / <条件串>b40 [@某人]` | **条件40**：旧系数口径（FiNALE 系数重算，25+15 拆分），可与回到过去叠加（如 dx2022b40） |
| `ap50 [@某人]` | AP 判型特例（等价「神50」）：只统计 AP/AP+ 的 best50 |


## 段位认定（dan）

| 指令 | 说明 |
|---|---|
| `段位` | 列出当前版本可用段位 |
| `段位 <段位名>` | 段位认定卡（课题曲/血量规则；绑定后含玩家达成率与底分预测，未绑定降级为 0.0000%） |
| `段位 <版本前缀><段位名>` | 跨版本段位卡：前缀=完整版本名或前 n≥3 字符+「+」表 PLUS（dx/dx+ 特例 2 字符，如 `bud+裏皆传` `dx初段`），国服形式 `舞萌dxYYYY / 舞萌YYYY / dxYYYY / YYYY / dx无印`（随心配口径）；不带前缀为当前版本 |
| `段位 <随机档名>`（如 `段位 MASTER超上级` `段位 紫超上`） | 随机档位段位卡：按档位规则真实抽四曲（独立抽取可重复，master 含 Re:MASTER）；抽曲区域随数据源（国服源不出日服限定曲）、可叠加版本前缀限定「到该版本为止」的曲库；`段位 随机` 出 8 档规则总览（合并转发） |
| `刷新段位` | SUPERUSER：手动拉取 arcade-songs 段位歌单入库 |
| `minfo <ID|曲名|别名> [@某人]` | 单曲成绩卡（@某人 代查其成绩）。曲名/别名同时命中标准谱与 DX 谱时列出两条 id（同「是什么歌」），用 `minfo <ID>` 指定要看的谱面；写 `minfo dx<别名>` 可直接看 DX 谱。要看的这张谱面（标准谱或 DX 谱）没有任何难度成绩时提示「尚未游玩过该曲目」，不输出全灰的成绩卡 |
| `ginfo [绿黄红紫白]<曲>` | 谱面游玩统计 + 评级分布图 |

> 日服 NET 数据源（`数据源 2`）支持 `b50` / `b40` / `minfo` / `ap50` 与完成表、进度、
> 分数列表等全量成绩功能；牌子查询按数据源牌单收口：国服可查至「彩」（PRiSM
> PLUS）代、日服可查至「回」（CiRCLE PLUS）代，越界会给出明确提示。
> NET 查询采用窗口缓存：一次抓取（约 5-15 秒）后窗口内（默认 15 分钟，
> `AWMC_NET_COOLDOWN_MINUTES` 可调）重复查询秒回，防止官方风控。
> 水鱼公开查询的凭据优先级：绑定用户名 > QQ 号（聊天 QQ 与水鱼账号 QQ 不一致时以用户名为准）。

## 条件组合查询

在查分与表格指令的条件串位置写条件词即可组合过滤，条件可任意叠加
（同类「或」、跨类「且」），例：`辉50`、`东方50`、`雪辉dx50`、`紫谱将50`、
`祝将50`、`14+sss+进度`、`东方fc完成表`、`14.5定数`、`dx2024b50`、
`拟合理想50`、`音击50`。`@某人` 代查同普通用法。

| 条件类 | 条件词 |
|---|---|
| 版本 | 版本字（辉/雪辉/真超檄…多代连写；真含初代、舞=旧作全集） |
| 世代/新旧 | dx、旧框、新版本、旧版本、新歌；回到过去：dx2024/舞萌dx2024/dx无印（新旧分界移到该年，定数取时点值） |
| 分类 | 东方、中二（中二节奏/chunithm）、音击（ongeki）、音击中二（中二音击，大类）、流行动漫、其他游戏、maimai、v家/术力口/niconico/ボカロ |
| 谱面 | 紫谱、白谱、绿、黄、红、13级、14+级、14.5定数、谱师名、宴谱、标准、dx谱 |
| 成绩 | fc/全连/极、fcp、ap/神、理论/ap+/app、舞舞/fdx/fsd、fs、fsp、将/鸟/sss、大将/鸟加/sss+、纯\<档\>/仅\<档\>（严格等于）、霸/clear（≥A）、牛逼（≥100.8）、越级（<95）、一星~五星、寸、锁/锁血/名刀/血压 |
| 修改 | 理想（升一档重算 RA）、拟合（拟合定数重算，缺失回实际定数） |

- **条件50**：跨等级条件平铺展示；纯成绩类按 35/15 拆分
- **条件40**：旧系数 b40（25+15）；回到过去恒拆分
- 组合语义：同类「或」（如 牛逼越级=任一命中）、跨类「且」（如 东方神=东方曲 ∩ AP）
- 等级/定数在 50 尾缀须带「级」「定数」字样（`13级50`）；进度/完成表/分数列表等中文尾缀裸数字即可（`13+sss+进度`）
- 谱师名直接写实名（如 まぐランド）；未命中任何条件词时静默不响应

## 表格（tables）

| 指令 | 说明 |
|---|---|
| `<条件串>定数表` | 定数网格表：`13+定数表`、`雪辉dx定数表`（跨等级按标级大类分组） |
| `<条件串>完成表 [@某人]` | 达成度盖章完成表：`13fc完成表`、`东方fc完成表`、`暁将完成表`；无达标条件按达成率 ≥80% 盖章（达标白底/不达标黑底/未打无底） |
| `<条件串>进度 [页] [@某人]` | 总览/已完成/未完成/未游玩：`13fc进度 2`、`东方未完成进度`、`真将进度` |
| `<条件串>分数列表 [页] [@某人]` | 按达成率降序 80/页：`13+分数列表`、`东方分数列表 2` |
| `<版本><牌种>完成表 [@某人]` | 牌子完成表（牌组合自动识别）：`真极完成表` / `樱极进度` / `舞舞进度`（牌种按各代真实牌表校验，如真代无极将、霸仅者）；@某人=代查 |
| `牌子条件` | 牌子达成条件说明 |
| `更新定数表 / 更新完成表`【SUPERUSER】 | 重建预渲染底图（改版/升级后执行；日常查询实时渲染无需更新） |

条件串写法见「条件组合查询」；等级（13/13+）、定数（14.5）、评价值
（fc/sss+/fdx…）为条件词的特例形态，触发文本与旧版完全一致。
