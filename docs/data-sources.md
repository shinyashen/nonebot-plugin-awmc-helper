# 数据源与绑定说明

本插件的数据层是 [maimai.py](https://github.com/TrueRou/maimai.py)（maimai-py），
涉及三个第三方服务与两个官方接口。

## 服务总览

| 服务 | 用途 | 鉴权方式 |
|---|---|---|
| 水鱼查分器（diving-fish） | 曲库、玩家/B50、全量成绩、曲线统计、RA 排行 | OAuth 机密客户端（部署级）；用户凭据见下表 |
| 落雪查分器（lxns） | 曲库（含物量）、玩家/成绩、AP 数据 | 开发者 Token（部署级）；个人 Token / 好友码（用户级） |
| 柚子（yuzuchan） | 别名读取、别名申请/投票、别名推送 | 无 |
| 华立（wahlap） | 机厅 location 数据 | 无 |
| maimai でらっくす NET（日服官方） | 日服 B50（maimaidx.jp） | SEGA ID + 密码（用户级） |

## 水鱼绑定

水鱼已要求所有成绩写入走 OAuth（开发者 Token 于 2026-10-01 日落），
本插件以设备码授权完成绑定：

1. **OAuth 授权**：`绑定水鱼`（QQ 平台）返回授权链接，在水鱼授权页登录并
   同意后，把页面给出的确认码发给 bot 即完成；read+write 一次带齐，全功能可用
   （含成绩写入/导分）。
2. **公开查询档**：`绑定水鱼用户名 <用户名>`（水鱼个人页显示的用户名）。
   可用：玩家信息、B50、RA 排名。
3. **全量成绩档**：`绑定水鱼token <Import-Token>`。
   额外可用：全量成绩（ap50、完成表、进度、分数列表）。

   Import-Token 获取方式：水鱼查分器个人页 → 设置 → 生成 Import-Token。

## 落雪绑定

1. **OAuth 授权（推荐）**：部署配置 `AWMC_LXNS_CLIENT_ID/SECRET/REDIRECT_URI` 后，
   `绑定落雪` 返回授权链接；用户回填授权码（20 分钟内有效），
   插件换取个人 Token 并自动记录好友码。
2. **直绑**：`绑定落雪 <个人Token>` 或 `绑定落雪 <好友码>`。
   好友码查询需要部署配置落雪开发者 Token。

## 日服 NET 绑定（数据源 2）

面向日服（maimai でらっくす NET，maimaidx.jp）玩家：NET 无第三方查分 API，
插件以 SEGA ID + 密码登录官方站抓取记录页，配合内置日服曲库（日服定数、
日服现行版本划分 b35/b15）组装 B50。

1. `绑定日服 <SEGA ID> <密码>`：**仅限私聊**（密码不进群聊记录）。
   绑定即验证登录（密码错误不保存），并自动切换数据源为日服；
   也可 `数据源 2` 手动切换。
2. 当前支持指令：`b50` / `minfo` / `ap50`，以及完成表、进度、分数列表等
   全量成绩功能（2026-09-30 起）。NET 以「窗口缓存」方式交互——一次抓取
   （约 5-15 秒，抓取前会先发提示）拿到全量成绩后，冷却窗口内（默认 15 分钟，
   `AWMC_NET_COOLDOWN_MINUTES` 可调）以上指令共享同一份数据、秒回且不再
   请求官方；窗口过期后再次查询会重新抓取。

   口径说明：完成表 / 进度 / 分数列表的曲库网格维持国服视图——日服限定曲
   不在网格内（自然缺席），共享曲目显示国服定数；牌子查询暂不支持
   （国服牌单与素材尚未适配日服），会给出明确提示。

**风险须知（务必阅读）**：

- NET 无第三方授权机制，抓取只能凭 SEGA 账号密码完成，密码级别敏感；
- 密码仅保存在本机 localstore 数据目录的 `awmc.db`，用于登录官方站，
  不上传任何第三方；绑定指令**仅限私聊**（群内会直接拒绝），且
  **不要使用与其他服务相同的密码**；
- 官方页面改版会导致解析失效，届时相应指令会给出明确错误提示；
- 频繁抓取可能触发官方风控，插件侧已内置冷却，请勿短时间反复查询。

## 凭据与隐私

- 用户凭据（水鱼 Import-Token、落雪个人 Token、日服 SEGA 密码）只保存在本机
  localstore 数据目录的 `awmc.db`（SQLite），**不会上传到任何第三方**；
  请妥善保管服务器与数据目录的访问权限；
- 查分器侧的隐私限制（水鱼「禁止第三方查询」、落雪隐私授权）触发时，
  插件会给出明确的开启引导，不会重试轰炸；
- `我的绑定` 指令对 Token 与 SEGA ID 做打码显示。

## 第三方接口风险

柚子别名投票/SSE、水鱼 RA 排行、华立机厅为非官方接口，可能随上游变动。
NET 抓取虽走官方站，但同样依赖页面结构。相关实现全部收敛在 `core/ext`
（含独立测试与降级文案），接口失效只影响对应功能，不影响其他指令。
